# Patadas Survivor

Juego web original de supervivencia con 13 personajes personalizados.

## Probar
Abre `index.html` en un navegador. Para publicarlo, sube `index.html` y la carpeta `assets` a un repositorio de GitHub y activa GitHub Pages desde Settings > Pages.

## Controles
- PC: WASD o flechas.
- Tablet: botones de dirección debajo del juego.
- El ataque es automático.
- Cada enemigo derrotado entrega 5 monedas.
- Sobrevivir da monedas extra al terminar la partida.
- La puerta cuesta 1,000 monedas y desbloquea personajes en orden fijo (sin azar).

El progreso se guarda en el navegador del dispositivo mediante localStorage.
